# ReadAssist v1.8.0 Release Notes

## 🚀 Major Updates / 主要更新

- **Full Multi-language Support / 全新多语言支持**：Switch UI between English and Chinese anytime. 界面可在设置中一键切换中英文，自动适配系统语言。
- **All User Text Internationalized / 全面国际化**：No more hardcoded text, seamless language switch. 所有用户可见文本彻底国际化。
- **Supernote & iReader Experience / Supernote/掌阅体验优化**：Smoother screenshot & floating button triggers, friendlier permission prompts. 截屏、悬浮按钮触发AI更流畅，权限提示更友好。
- **AI Chat Window Enhanced / AI对话窗口增强**：Select and long-press AI reply text to auto-copy for follow-up. 支持滑动选择AI回复文本，长按自动复制到输入框。
- **README Rewritten / 文档重写**：English & Chinese README now concise and user-focused. 中英文README全面简化，突出核心卖点和上手流程。
- **Bug Fixes & Performance / Bug修复与性能提升**：Fixed residual Chinese, menu, dialog issues; faster startup and response. 修复部分设备权限提示、菜单项、弹窗等残留中文，优化启动和响应速度。

## 🛠 How to Upgrade / 升级指南

1. Download the latest APK from [Releases](https://github.com/James-Zhu-CA/ReadAssist/releases).
2. Enable "Unknown Sources" on your device. / 允许未知来源安装。
3. Install and grant overlay + accessibility permissions. / 安装并授予悬浮窗和无障碍权限。
4. Enter your Gemini API Key ([Apply here 申请地址](https://aistudio.google.com/welcome)).
5. Tap "Start Service" and enjoy! / 点击"启动服务"即可。

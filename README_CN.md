## 概述
ReadAssist 是为 iReader、Supernote 等墨水屏设备量身打造的 AI 阅读助手，借助 Gemini 2.5 模型解析截图、识别手写批注，让学习更高效。

## 亮点
- **墨水屏优先**：界面与交互专为 E-ink 调优
- **一键 AI**：截屏即分析，秒出结果
- **识别手写**：懂高亮、批注与涂鸦
- **悬浮聊天**：极简气泡对话，不打扰阅读
- **离线友好**：记录本地保存，可随时导出
- **中英双语**：设置里即时切换

## 支持设备
• iReader X3 Pro 及其他带翻页键的 iReader 机型  
• Supernote A5X2 / A6X2（支持系统截屏与悬浮按钮）

## 快速开始
1. 在 [Releases](https://github.com/James-Zhu-CA/ReadAssist/releases) 下载 APK 并安装（需允许未知来源）。
2. 首次启动授予 **悬浮窗 + 无障碍** 权限。
3. 在设置里填入 **Gemini API Key**（每日 500 次免费）。申请地址：https://aistudio.google.com/welcome
4. 点击 **启动服务**，即可使用。

### 使用方法
**iReader**  
• 设置 → 长按 *上翻页键* = 截屏  
• 长按截屏后，聊天窗口自动弹出。

**Supernote**  
• 方法 1：下拉状态栏点 *截屏*。  
• 方法 2：点悬浮按钮 → 自动截屏并进入对话。

**小技巧**  
在聊天窗口选中 AI 回复文本并长按，可快速复制到输入框继续追问。
